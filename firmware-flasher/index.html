Chrome / Edge · ESP32

Astro Orbit Flasher

Firmware ohne VS Code installieren. USB schreibt ein vollständiges Image; OTA aktualisiert einen bereits laufenden Astro-Orbit-Controller.

USB installieren

  1. Astro Orbit per USB anschließen.
  2. Seriellen Monitor, NINA und andere COM-Programme schließen.
  3. Auf „USB Firmware installieren“ klicken und den Port auswählen.

Neuestes GitHub-Release wird geladen …

Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge am Desktop verwenden. Web Serial benötigt HTTPS oder localhost.

Beim erstmaligen USB-Flash kann der ESP32 seine gespeicherten Einstellungen verlieren, wenn im Dialog „Erase device“ gewählt wird.

OTA über WLAN

  1. Die normale astro-orbit-firmware.bin aus dem Release laden.
  2. Mit demselben Netzwerk wie Astro Orbit verbinden.
  3. Die Update-Seite des Controllers öffnen und die Datei auswählen.
OTA-Seite öffnen Firmware herunterladen

Die OTA-Seite wird absichtlich direkt vom Controller geladen. Dadurch blockiert der Browser die lokale HTTP-Verbindung nicht als gemischten Inhalt.
